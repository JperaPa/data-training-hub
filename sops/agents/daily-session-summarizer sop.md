# Daily Session Summarizer Agent — SOP

## Purpose
Capture, summarize, and store daily conversations between user and AI.

## Inputs
- Raw conversation transcript
- Date
- User goals
- Global SOP

## Outputs
- Markdown file saved to /logs/sessions/YYYY-MM-DD.md

## Summary Structure
- High-Level Summary
- Key Decisions
- Technical Actions
- Blockers
- Next Steps
- Alignment with Goals/SOPs

## Rules
- Be concise but complete
- Use bullet points
- Maintain chronological clarity
- Never store sensitive data
- Always overwrite or append safely
