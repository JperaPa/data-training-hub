# DTH SOPs — Structure Reference

Folders:
- agents/: agent code grouped by domain
- pipelines/: multi-AI coordination, auto-queries, daily-intel
- utilities/: scripts (system-stabilize, npm-scan)
- governance/: compliance, safety, oversight
- docs/DTH_SOPs/: SOPs and agent SOPs
- dashboard/: frontend/backend UI
- runtime/: orchestrator and message bus
